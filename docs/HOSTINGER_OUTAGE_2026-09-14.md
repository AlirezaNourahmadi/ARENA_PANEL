# گزارش قطعی Hostinger در ۱۴ سپتامبر ۲۰۲۶

## نشانه‌ها

- پنل و health endpoint در دسترس بودند، اما همه لینک‌های WebSocket از اینترنت مستقیم کاربر `-1` می‌شدند.
- آخرین نشست ثبت‌شده حدود ساعت ۰۵:۱۵ ایران بود.
- همان سرویس از یک مسیر VPN دیگر پاسخ می‌داد و آزمون داخلی Gateway/Xray نیز کامل موفق بود.

## عیب‌یابی

1. DNS، TCP/443، گواهی، health، کانتینرها، PostgreSQL، UFW، conntrack و حافظه بررسی شدند.
2. تست عمومی از مسیر جایگزین Google/Cloudflare و payload هشت MiB را عبور داد؛ بنابراین credential، Gateway و outbound سرور سالم بودند.
3. روی اینترنت مستقیم، TCP برقرار می‌شد اما TLS پس از ClientHello reset یا پس از handshake بدون پاسخ HTTP می‌ماند.
4. `tcpdump` روی VPS retransmit شدن پاسخ TLS و نرسیدن ACKهای بعدی را نشان داد. این الگو خرابی اپلیکیشن یا `/data` نیست و در مسیر شبکه رخ می‌دهد.
5. نگهداری اعلام‌شده دیتاسنتر اروپا با شروع قطعی هم‌پوشانی داشت، اما آزمون packet-level همچنین مداخله مسیر مستقیم را ثابت کرد.

## راهکار اجراشده

- WebSocket فعلی حفظ شد تا تمام کنترل‌های Gateway باقی بمانند.
- یک data plane مستقل VLESS/TCP/REALITY روی پورت `2053` اضافه شد.
- مقصد اولیه `www.microsoft.com` به‌علت کامل‌نشدن handshake با زنجیره گواهی آن رد شد؛ `www.google.com` در تست داخلی و اینترنت مستقیم موفق بود.
- لینک REALITY از دامنه public پنل تولید می‌شود و به IP یا localhost hard-code نیست.
- کلید خصوصی فقط در `.env` VPS است و در Git، دیتابیس، API یا log قرار نمی‌گیرد.
- حجم، تاریخ شروع، انقضا و IPهای آنلاین از StatsService به PostgreSQL منتقل می‌شوند.
- ruleهای محدودیت IP با ترکیب user و source IP در RoutingService ساخته و حذف می‌شوند.

## نتیجه آزمون پیش از ادغام

- Google generate_204 از اینترنت مستقیم: HTTP `204` در کمتر از نیم ثانیه در آزمون IP و حدود ۱.۳ ثانیه با hostname.
- payload هشت MiB: کامل دریافت شد، حدود `1.93 MB/s` در مسیر آزمایشی.
- IP ثبت‌شده در access log با IP واقعی اینترنت کاربر یکسان بود.

## مرز فعلی

محدودیت سرعت WebSocket توسط token bucket در Gateway اعمال می‌شود. REALITY مستقیماً به Xray می‌رسد؛ حجم و IP روی آن اعمال می‌شوند، اما shaping سرعت کاربرمحور در این شاخه پیاده‌سازی نشده است. این مورد باید در فاز بعد با data plane دارای rate limiter کاربرمحور حل شود.
